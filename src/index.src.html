A pocket multitool for the M5Stack StickS3. Two buttons and one tiny screen.

See the code on GitHub How to install it

What it does

  • Clock, timers and weather
  • Pi-hole stats and a one-press pause
  • Home Assistant lights and scenes
  • Wi-Fi, Bluetooth and infrared scanners
  • A remote that learns infrared codes
  • Buttons that fire any web request
  • Three small games and a virtual pet
  • A live sound spectrum from the mic

It hosts its own settings page

Open it from any browser on your Wi-Fi.

See what is on the screen, change settings, and send a message to the stick.

It updates itself

Point it at a firmware list on your network.

When a new build shows up, press one button. It installs over Wi-Fi.

How it is made

  • C++ for the ESP32-S3, built with Arduino.
  • No StickS3? Most of the code ports to other ESP32-S3 boards with a screen.
  • MIT licensed. Read the changelog.
